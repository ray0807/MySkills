# 商品场景图

先读 [references/cocoon-mcp.md](references/cocoon-mcp.md)。先查看商品参考图并理解用户产品；没有参考图时只能做明确标注的概念场景，不把模型虚构商品当真实商品。

缺少 Cocoon AI Key 时先请用户填写图片服务 Key 并配置连接；已有有效连接直接复用。配置完成后再生成，上传本地图缺少 COCOON_IMAGE_KEY 时也需先补齐。

## 工作流

1. 从用户描述和产品资料确定场景、受众及正确用法。缺少场景要求时选择与产品用途相符的自然环境，默认不放人物、不写字、1 张；不假定商品具有未提供的防护、防水、医疗或耐高温能力。
2. 锁定商品身份，设计主体位置、画面层次、光线、真实比例、支撑与接触关系。场景为商品服务，不让背景道具成为主角；不凭空加入实际销售套装不含的配件。
3. 提示词写商品参考身份 → 使用场景 → 构图/光线 → 正确接触关系 → 锁定细节与禁改项。添加人物时注明其动作与产品用途，并避免生成错误使用方式。
4. 使用 gpt-image-2-5-image-to-image + imageUrls。首图锁定商品，其余按风格/场景参考角色说明。默认 1K；有版位就沿用比例，未知默认 4:3，已有构图要保留则 auto。
5. 查看成品，核对商品结构、比例、材质、Logo、支撑与遮挡、使用动作及阴影。背景过度吸引注意、商品漂浮、人体畸变或错误用法标为不合格。生成场景是创意示意，不作真实用户、工厂或现场照片背书。

## 交付

展示实际图片，说明场景设计与真实性检查，并保留参考图/任务 ID/结果 URL。用户要求系列图时锁定同款商品、色系和视觉语言，但不承诺生成模型完全一致。
