# 免费社媒优先的渠道准入

当前默认 link-first：免费社媒搜索返回的相关链接/摘要即可收录，无需打开原帖，不要求用户接接口。能保存链接不代表已核验需求或免费联系。此规则优先于旧查询计划及历史渠道经验。

## 先确认宿主工具能力

同一 skill 在不同 agent 上的工具覆盖不同。开始前查看实际可调用工具的名称、说明和授权范围，记录简短 capability_map：工具、搜索范围、是否能读原帖、能否读评论、账号前提、此次实际读取结果。不要把其他 agent 的工具或客户编号当作当前环境已验证事实。

- 如果实际有 social.search 或类似社媒连接器，先读它的说明并小样本验证返回平台、原文链接、作者、评论和时间字段。能搜索不等于能读完整原文；有摘要但原帖无法读取仍保存为未核验 candidate，不能声称已实读。按实际覆盖优先使用，不强制名称或厂商。
- 如果有用户授权的已登录浏览器，使用站内搜索并实际读取有权限的原帖/评论；不能假定能读所有私密群。
- 只有网页搜索时，用 site: 平台定向查询作为发现入口，默认直接保存链接和可见摘要，原帖核验仅在用户另行要求时做。报告“网页索引覆盖有限”，不声称等同站内搜索。
- 社媒原文/评论读取受限时，默认无需读取，继续收录真实搜索返回的相关 URL/文本，分别标记候选与发现入口。没有搜索结果时如实说明；不要求用户配置 API、Key 或爬虫服务，也不把收费站当替代。

通用 tender / buy offer 查询应特别审查聚合/交易平台结果，不假定搜索排名代表免费可用。排除源可以帮助发现独立官方原公告，但不能交付聚合页、注册入口或它的联系人；找不到独立原始证据就结束该候选。工具名称不证明私密群覆盖，搜索摘要也不证明已访问原文。

## 搜索顺序

1. Facebook：相关公开群组中的买家求购、求推荐帖，以及能实际读取的评论。先判断群组是否相关，再找具体帖子和作者；群组目录不是客户名单。
2. YouTube：用户自述采购/改造问题的视频，及评测、安装、竞品视频下实际表达需求的评论。卖家频道和泛泛互动不能算买家。
3. Instagram：帖子、Reels 和实际评论里的采购、补货、品牌定制、替换和求推荐表达。评论者与视频发布者分开。
4. 按产品补充 Reddit/行业论坛、LinkedIn、X、Threads、TikTok；买家官网明确需求与免费官方原公告为补充，不能抢占社媒搜索主线。

按产品、可用工具和预算选择优先组合，不声称每次读遍所有平台。平台可访问性和联系权限必须当次核验，不宣称这些平台全部免登录或评论均可被搜索引擎收录。

## 直接排除，不作默认备选

- 阿里国际站、Made-in-China、Global Sources、go4WorldBusiness、Tradewheel、TradeKey、EC21、ECPlaza、IndiaMART、TradeIndia 等 B2B 交易/采购平台。
- 采购联系人库、会员线索目录、付费招标聚合站，包含用户已排除的 govttenders.co.in。
- 付费才能查看、回复、拿联系方式或提交询价的路径。

常见域名维护于 [source-policy.json](../assets/source-policy.json)，供脚本拦截主域及子域；不是完整全网黑名单。AI 必须识别新域名的实际类型，写 source_kind=b2b-marketplace/lead-directory/paid-aggregator。即使某条可免费看，B2B 类来源仍排除。搜索可使用 -site 排除，但最终以原文来源审查，不能只靠搜索过滤。

偶然遇到的排除项只记 reason 和计数；已入主库的保留审计并导出 excluded.csv，不出现在交付客户表或“推荐注册”列表。禁止因为社媒难读而回退到这些网站。用户以后明确要求 B2B 模式时需另行调整规则，不在当前流程自行放开。

## 登录与免费联系

- public：实际可读取原文；公开商务邮箱、官网联系表单等免费路径另核验。
- existing-authorized-account：用户已登录且明确授权只读的现有账号。验证可访问原帖/评论和免费业务联系路径，说明要使用该账号。
- registration-required：需要新注册/登录但未提供授权账号、申请加入群组或等待权限；不进入可跟进名单。blocked 是访问状态，不代表没需求。
- unknown：权限不足以确认，进入待核验，不猜“可以私信”。

contact_path=free-registration 保留兼容，但只有 existing-authorized-account 且已有免费联系证据才能进入可跟进；仍需新注册的不行。看得到账号不代表有私信通道，能评论不代表私信开放。找不到可用免费路径就明确说明。任何发消息、评论、加好友或申请加群都需要用户另行授权。

## 覆盖与增量记录

channel_runs.jsonl 每个查询记录：run_at、topic_id、query_id、language、platform、channel、query、segment、layer、window_since、window_until、status、http_status、fetched_count、verified_count、eligible_count、noise_count、error、next_check_at。

status 为 ok/empty/blocked/error/not-tested。只有真实完成读取/解析才能 empty；仅搜索到视频但没读评论不能记已覆盖评论。成功查询推进自己的窗口，失败和未完成的下次补查。工具失败最多重试一次；429 尊重 Retry-After，登录墙/验证码不反复重试或绕过。连续成功零合格调整词族/语言/场景，连续失败降频，按产品记录原因及下次复查时间，不永久判死。

默认日报先呈现待核验链接与发现入口，已有核验客户另列。搜索完成与原帖核验是两个范围：不读取原帖本身不使链接收集任务失败或 partial；实际查询未完成才 partial。排除项仅汇总，不用付费页面填充客户数量。
