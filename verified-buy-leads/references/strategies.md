# 外贸获客方法

每种方法标明产出类别：
- **明确需求**和**潜在需求**进入主线索库（`leads.json`），评级规则见 evidence.md。
- **开发名单**是没有公开表达需求、但有合理理由主动联系的公司，保存到 `signals.jsonl`，在汇报中单独列出，不计入线索数。

只用无需付费即可查看的公开内容；登录墙、付费解锁和验证码不绕过。每个平台的可达性和免费字段都需要当次核验，下表中的平台名只是候选，不代表一定可用。

## 一、公开求购与 RFQ（明确需求）

| 方法 | 怎么找 |
| --- | --- |
| B2B 平台求购 | Alibaba RFQ、Made-in-China 采购需求、Global Sources、go4WorldBusiness、Tradewheel、TradeKey、EC21、ECPlaza、IndiaMART / Tradeindia 买家需求等的公开求购页 |
| 搜索引擎指令 | `"looking for supplier" "产品词"`、`"request for quotation" 产品词`、`intitle:RFQ 产品词`、`"we are looking for" 产品词 manufacturer`，配合目标语言版本 |
| 社媒求购帖 | LinkedIn 公开帖（"looking for a supplier of"）、Facebook 公开群组、X 搜索、Reddit 的 ISO / WTB 帖 |
| 众筹和初创公司 | Kickstarter、Indiegogo、创业社区中"looking for manufacturer"的帖子 |

## 二、政府与机构招标（明确需求）

| 方法 | 怎么找 |
| --- | --- |
| 国际组织 | UNGM、World Bank、亚洲开发银行（ADB）、非洲开发银行等采购公告 |
| 地区与国家门户 | 欧盟 TED、美国 SAM.gov、英国 Contracts Finder / Find a Tender、加拿大 CanadaBuys、澳大利亚 AusTender、沙特 Etimad 等目标国家官方门户 |
| 搜索引擎 | `filetype:pdf tender 产品词 2026`、当地语言的招标词（licitación、appel d'offres、مناقصة） |

招标先读资格要求。需要当地合作商的单列；中标公告是采购历史，放进开发名单。

## 三、终端客户痛点（潜在需求）

| 方法 | 怎么找 |
| --- | --- |
| Reddit | 相关子版块，加 `site:reddit.com` 搜痛点词和求推荐句式 |
| 行业论坛和社群 | 按 segment 找垂直社区（如教会技术、餐饮经营、健身房经营、零售店主论坛）、公开 Facebook 群组 |
| 问答网站 | Quora、Stack Exchange 相关版块、本地语言问答网站 |
| 评论区 | YouTube 产品评测和教程的评论、行业博客评论区 |
| 竞品差评 | 被替代方案或竞品在电商、Google 地图、Trustpilot 上的差评，作者是终端客户且产品能解决时记为潜在需求（多为纯吐槽，定 C） |

## 四、触发事件（开发名单）

| 方法 | 怎么找 |
| --- | --- |
| 开业和扩张新闻 | 当地新闻、商业媒体中的新店开业、新场馆、翻新、扩建、搬迁 |
| 建设和装修许可 | 公开的建筑许可、规划公告、场馆建设项目 |
| 招聘信息 | 招聘相关职位（如 AV 技术员、标识经理）的公司，说明正在投入该领域 |
| 融资和政府项目 | 获得融资的公司、公布的政府或城市建设项目 |
| 大型活动 | 即将举办的展会、体育赛事、音乐节，以及负责搭建的公司 |

触发事件只说明可能有需要，不代表正在采购。开发名单写清触发事件和建议的切入点。

## 五、进口商与渠道客户（开发名单）

| 方法 | 怎么找 |
| --- | --- |
| 海关和提单数据 | ImportYeti 等免费的美国提单查询：搜同类产品或竞争对手，找到实际进口商 |
| 竞争对手的客户 | 竞品官网的案例、合作伙伴、经销商页面 |
| 展会参展商名单 | 目标行业展会公开的参展商和往届名单（如 ISE、InfoComm 之于 LED 屏） |
| 行业协会会员名录 | 目标国家行业协会的公开会员目录 |
| 企业名录 | Europages、Kompass 免费部分、ThomasNet、Yellow Pages、当地商会名录 |
| 地图搜索 | Google 地图搜"产品词 + installer / distributor / supplier + 城市"，找本地经销商、安装商和集成商 |
| 政府采购历史 | 中标公告中的中标方，往往是当地合作商或经销商 |

## 每次运行的组合

预算有限时，每次运行至少覆盖：一个明确需求渠道、一个痛点社区，以及一个触发事件或渠道客户方法。各方法的结果分别计数，便于看出哪种方法最有效；连续多次无产出的方法降低频率，但不永久放弃。
