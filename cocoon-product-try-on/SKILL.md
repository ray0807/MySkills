# 试穿试戴

先读 [references/cocoon-mcp.md](references/cocoon-mcp.md)。查看商品图与人物图，确定参考角色：商品决定款式，人物决定身份/姿态，其他图只作风格参考。使用用户提供或获授权的人像，不擅自选用网络真人照片。服务会接收参考图，按用户任务范围处理。

缺少 Cocoon AI Key 时先请用户填写图片服务 Key 并配置连接；已有有效连接直接复用。配置完成后再生成，上传本地图缺少 COCOON_IMAGE_KEY 时也需先补齐。

## 工作流

1. 商品参考是必需；指定真人效果需要人物参考。没有人物图但用户接受虚拟模特时生成成人虚拟模特，并标为虚拟展示，不宣称是本人试穿。缺少必要角度或佩戴部位时先提示补图。
2. 识别衣服/眼镜/饰品的结构、颜色、图案、材质、商标和佩戴位置。锁定人物面部、发型、体型、肤色、姿态和原背景，除非用户明确要求改变。不顺便瘦身、美白或改人脸。
3. 提示词明确每张参考图角色、替换的服饰/配饰及要保留的内容。服装核对领口/袖口/长度/褶皱；眼镜核对鼻梁、镜腿和耳部；首饰核对挂点、重力与遮挡。未知商品真实尺寸不捏造数值。
4. 使用 gpt-image-2-5-image-to-image、imageUrls、aspectRatio=auto、resolution=1K、1 张；参考顺序与角色在提示词中逐一说明。接口没有 garment/person/mask 专属参数，不能把通用图生图说成有专业尺寸建模能力。
5. 查看成品：人物是否仍匹配，商品是否改款，左右是否合理，眼镜/首饰是否穿入身体，手指/耳部/头发遮挡是否自然。结果不用于断言尺码合适、舒适度或真实防护效果。

## 交付

展示实际试穿/试戴图，标为 AI 虚拟效果示意，说明商品和人物一致性检查。存在变形或身份漂移时具体指出，不能只交付漂亮图片并声称完全真实。
