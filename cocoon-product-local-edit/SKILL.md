# 局部修改

先读 [references/cocoon-mcp.md](references/cocoon-mcp.md)，查看原图。必须明确“改哪里、改成什么、哪些内容保持不变”；已有描述充分就执行，位置含糊时询问，或请用户标注，不凭猜测改关键商品结构。

## 工作流

1. 识别区域，用可定位语言描述，例如“左上角背景中的纸杯”或“护目镜右侧镜腿末端”。记录锁定区域：商品其他结构、Logo、文字、背景、人物、尺寸与裁切。
2. 使用原始未标注图为基底；标注图作为辅助区域说明，不能让圈线进入成品。先核实当前 schema：本服务已知只有 imageUrls + prompt，没有 mask 参数；不能伪造遮罩字段或宣称精确局部重绘。
3. 提示词先写修改目标，再写位置与预期变化，最后明确保持区。指定色值用于意图描述，不承诺模型输出精确色彩或实物色差。
4. 默认 gpt-image-2-5-image-to-image、aspectRatio=auto、resolution=1K、1 张。原图首位，其余参考分别说明用途。修改文案需用户提供准确文字，不创造宣传承诺；重要文字最后核对。
5. 查看结果，分别检查修改区是否达到目标、其他区域是否发生漂移。画面整体改写不能标为局部修改成功。失败保留结果与原因，不自动循环扣费。用户要求像素级保持且接口不支持时说明需要确定性合成/专门遮罩能力，不承诺当前生成服务能做到。

## 交付

展示修改前后可用图片，列出本次修改及保持区检查。明确这是生成式编辑；不能核验的部分标为待人工检查。
