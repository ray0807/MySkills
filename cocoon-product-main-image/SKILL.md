# 商品主图

先读 [references/cocoon-mcp.md](references/cocoon-mcp.md)，检查连接与参考图。使用用户指定的 Cocoon MCP，不擅自替换成其他生图服务。真实商品必须有参考图；仅有文字时先说明只能制作概念图，等待商品图或用户明确接受概念展示。

## 工作流

1. 查看商品图，识别产品主体、件数、轮廓、颜色、材质、结构、商标和包装。多图有矛盾时确认哪张代表实际商品。缺少底面等不可见信息不补造。
2. 用已有要求确定平台用途。没有指定时默认 1 张 1:1、中性白底、完整商品、自然接触阴影、不加文字/道具/赠品。只有用户提及特定平台合规要求时查询其当前官方规则，不宣称默认图已获平台认证。
3. 组织图生图提示词：商品身份与锁定细节 → 构图/视角 → 背景/灯光/阴影 → 不允许的变化。修饰照明和背景，不把便宜材质变成另一种材质，不新增功能或认证标志。用户明确要求换色/变款时记录是变体，不当作原款。
4. 调用 generate_image，默认 model=gpt-image-2-5-image-to-image、aspectRatio=1:1、resolution=1K、background=opaque。imageUrls 首图为商品主体，其余为同款细节参考。用户指定更高分辨率/透明背景时采用实际支持参数。
5. 查询任务并查看实际结果，与原图对比轮廓、颜色、件数、Logo、标签、比例、裁切和边缘。Logo/文字失真、产品改款或遮挡关键部分时标为不合格，不以“好看”替代真实性。无查看能力则标“待人工检查”，不声称通过。

## 交付

展示实际主图，给任务 ID、结果链接、比例与已核验要点。需要调整时描述具体问题，用户未要求多图不批量生成。保留原图引用与最终提示词，方便做一致风格的后续主图。
