# 配图与媒体

先确定图片承担什么信息：封面表达主题，正文图解释规格、流程、比较或真实场景。产品外观、认证标志、尺寸和结构必须与真实产品一致；有品牌资产优先用它。生成图片不能伪装真实工厂、客户、采访或新闻现场，必要时标注“示意图”。

数字对比图、数据图和技术结构用真实数据及确定性绘图工具；不要让生成图片承担准确数值或标准标识。需要照片/插画时使用可用图片生成工具，遵守对应技能。文字密集图避免生成模型输出不可读文字。

素材可来自用户提供、明确许可库、自己的生成结果或原创绘图。搜索到图片不等于允许转载；记录具体授权依据，不下载远程媒体以规避工具显示限制。缺少权限更换素材。

每张图 `media.json` 保存：asset_id、local_path、role（cover/body）、alt、caption、placement、origin（user/licensed/generated/chart）、source_url、license_or_permission、generation_prompt（如适用）、width、height、upload_status、remote_url、media_id。没有 URL 的本地生成图不填虚构 URL。

查看实际图片，核对内容、产品真实性、文字、裁切、可读性与文章关系。alt 描述信息，不堆关键词。图片尺寸、比例、格式和文件大小服从站点上传 schema；上传后检查返回 URL/媒体 ID，正式正文使用平台能访问的引用。使用平台媒体 ID 渲染的接口无需强行转成公开 URL。

若媒体上传成功但文章发布失败，保存媒体 ID 并复用，不自动删除远程媒体。图工具不可用且配置要求封面时，整篇保留为草稿；不静默用提示词或损坏链接充当图片。
