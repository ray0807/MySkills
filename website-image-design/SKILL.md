# 网站开发的 Cocoon 生图工具

这是网站开发的生图能力补充。照常理解需求、查看项目、设计、修改文案与代码、预览和测试，不另设固定访谈、风格菜单、阶段审批或批次表单。用户已明确的范围、参考和授权直接采用；必要歧义按正常协作方式澄清。使用说明见 [README.md](README.md)。

## 何时使用

需要网站 Banner、场景图、产品配图等位图素材时，使用用户指定的 Cocoon MCP。AI 根据页面实际需要决定图片数量、构图、比例、主体与留白；现有资源或 CSS/SVG 足够时直接复用或实现，无需配置生图服务。页面其他修改沿用正常开发流程，不受本 skill 限制。

截图、框选、文字、提示词或网站可以混合参考。实际查看可访问的页面与图片再提炼风格，不凭域名猜测。根据产品和具体用途认真分析场景、人物/道具必要性与物理关系，确定合理后再付费生成，不靠生图试错替代产品理解。真实产品以原图为依据，不杜撰不可见结构、配置或兼容性；资料不足选可信替代或说明缺口。

## 如何调用

首次需要生图时读 [Cocoon 工具说明](references/cocoon-mcp.md)，复用实际已连接的工具，按当前 schema 调用，不擅自换服务。缺 Key 才引导私密配置；没有 Key 引导到 https://mcp.boomclaws.com/ 注册登录获取。已有有效连接不重复索取 Key。

生图前查余额，简述数量、规格和可核实费用；已有相应授权直接执行，不逐图询问。费用范围不明确时按实际需要澄清，不把普通代码修改自动理解为无限付费生成。额外重做遵守授权，费用未知如实说明。

本地参考先查看，再用 scripts/upload_reference.py 上传取得 URL，角色写进提示词。网站页面 URL 和本地路径不能直接传作 imageUrls。记录实际提示词、taskId、结果与已返回费用，以便恢复；不用建立整套设计档案或固定 JSON 状态机。

提交后取得 taskId 就继续查询同一任务；超时没有 ID 时先核验，不盲目重提。长任务等待时继续独立开发工作并报告进度，不默认停下等“继续”。明确故障或余额不足时说明阻塞，完成其他可执行工作。

## 接入与检查

按实际文件类型将结果保存到项目惯用资源目录，再接入页面，不依赖可能过期的临时链接。保留可恢复的原资源，按项目惯例压缩、生成尺寸变体和设置响应式裁切。标题与按钮通常留在网页代码中。

查看生成图并在实际页面检查桌面/移动效果。产品失真、不合理交互或错误文字不能当作合格图；无额外重做授权时说明问题并采用可信回退，不擅自追加付费。保存失败先恢复已有结果，不再生成。

按正常开发方式完成代码与相关功能验证，报告实际修改、资源位置和未验证项；生图费用按唯一 taskId 去重汇总，缺记录不猜，余额差额不能代替任务扣费。没有生图就无需生图报告。部署、Git操作等沿用用户与项目既有指令，本 skill 不添加新流程。
