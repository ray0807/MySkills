# 用户引导与异常提示

## 使用顺序

1. 开场：“我会先检查产品文件夹，再帮你选择平台、每款张数和图片风格，选好后连续生成整套。请提供产品根目录路径。”给出最短结构示例 `产品目录/产品名称/原图.jpg`。有文件夹选择能力就使用，没有则索取路径，不假装弹出了窗口。
2. 扫描完成后说清楚产品数、可处理数、缺图数、多图待选数。产品少时直接列清单，多时先展示问题项。缺图可补图或跳过；多图且无唯一原图时展示候选缩略图，让用户选主图。不要根据扩展名就说图片已经有效解码。
3. 选择平台：阿里国际站 / 亚马逊 / 自定义。然后选择平台套图或全部白底；说明亚马逊通常是主图白底，附图不必全部白底。亚马逊询问目标站点、类目以核对规则，缺少时标设计稿待核验，不编造平台认证。
4. 选择风格：简洁商业摄影（默认）/ 工业科技 / 自然家居 / 自己描述 / 参考图片 / 参考网站域名或链接。网站模式先获取域名或链接，实际查看首页和相关页面，再总结配色、背景、光线、构图、道具和本批应用方式，附来源；无法访问时请用户提供截图或替换链接，不编造分析。按 references/website-style.md 执行。默认方图、1K、无额外文案；用户想调整时才展开尺寸、语言等选项。产品说明可选：缺参数不阻断无文案图片，只跳过依赖参数的内容。
5. 第一次上传前检查 MCP 连接与 Key。缺连接给出服务地址、Streamable HTTP、Authorization Bearer 的填写位置和配置模板；缺 Key 请在客户端私密配置填写。没有 Key 时提供 https://mcp.boomclaws.com/，说明注册登录后到管理页获取。不要让用户发完整 Key 到聊天。仅上传环境缺配置时，说明把同一 Key 配置为本机 COCOON_IMAGE_KEY；有安全私密配置能力可协助，否则给本机设置步骤，不声称已自动设置。完成后验证，失败只描述认证问题，不回显凭据。
6. 询问每款每个平台张数（1 / 4 / 6 / 自定义），由 AI 规划图位。连接成功后查询余额，按实际单位和精度显示，列出整批总张数和可核实费用。没有单价就标费用未知。数量和风格选定后连续完成所有任务，不中途以“样图完成，请回复继续”结束；用户明确要求先出样时才等待样图确认，样图包含在总张数内。默认不额外重做扣费。余额不足给“自行充值 / 减少图片 / 暂存”的选择，充值后重查。
7. 运行中简报“已保存 X/Y 张，Z 张需要确认”，长任务每60秒内更新一次，有变化再展开原因；不用把工具参数和轮询日志全部展示给用户。每张立即保存进度，用户停止时停止新提交，保留已提交任务 ID，并说明已提交任务可能仍在服务端执行。
8. 完成或停止后再次查询余额，展示当前余额、实际可核实扣分及未确定费用；余额查询失败时注明无法刷新，不把旧值冒充当前值。余额变化可能受充值或其他任务影响，不用前后差额替代本批费用。提供预览、保存目录、成功数、跳过数、失败数、待确认数；给出自然语言重做示例：“只重做保温杯第二张，背景换成浅灰”。有未落盘结果时明确指出，不能把结果链接算作本地保存完成。

## 问题提示原则

提示包含具体产品/图位、可确定的原因、是否已提交或可能扣费、下一步。拿不准就说明尚未确定。一次列出同类问题，避免逐个弹窗打断。不要求用户处理可以自行修复的常规路径、版本命名和排版选择。

| 情况 | 提示与下一步 | 是否继续 |
| --- | --- | --- |
| 路径不存在、无法读取 | 展示所用路径，请用户重选路径或开放该目录访问 | 暂停扫描 |
| 根目录没有产品子文件夹 | 给结构示例，提示可能选到了单个产品文件夹 | 等待更正目录 |
| 没图、损坏或格式不支持 | 指出产品与文件；请求补充可查看、可上传的 PNG/JPEG/WebP 等；不擅自改原图 | 可跳过该产品 |
| 扫描格式与上传不一致 | BMP/TIFF 可能可扫描但上传脚本不支持；上传前说明，提供另存为支持格式的选项；不等到付费生成后才报错 | 其他产品继续 |
| 多图或不同商品混在一起 | 展示候选并询问主图/同款身份，未确认前不上传错误商品 | 暂停该产品 |
| 缺尺寸、认证或背面参考 | 说明相关图位缺依据，可补资料、改为无参数图片或跳过 | 其他图位继续 |
| 缺 Key/连接/上传配置 | 按上面第5步提示；注册获取 Key 由用户完成，不自动注册或充值 | 可继续规划，暂停上传生成 |
| 余额不足 | 说明余额和已知费用，请用户选择自行充值、减少数量或保留任务 | 停止新提交 |
| 有 taskId 但未完成 | 说明正在等待，保存进度；轮询到时报告 ID，后续继续查同一任务 | 不重复提交 |
| 提交超时且无 taskId | 明确“提交结果未知，可能已生成或扣费”，请查看服务任务历史；核验前不重新提交 | 暂停该任务 |
| 明确任务失败 | 展示服务返回原因；费用/退款未核实就说未知，提供稍后重试的选择 | 独立任务可继续，整体故障停批 |
| 产品外形/Logo/文字失真 | 指出具体差异，标待确认；已有迭代预算才重做，否则请用户选择 | 其他图位继续 |
| 图片无法查看 | 标明尚未做视觉检查，提供可用链接请用户查看 | 不标检查通过 |
| 保存失败/无目录写权限 | 保留结果 URL 和任务 ID，提示选择可写目录；恢复时只保存，不再生图 | 可按情况继续 |
| 原图或参考图改变 | 指出变化文件，提示新建批次；不使用旧状态当新任务完成 | 暂停受影响任务 |
| 工具未连接或字段不匹配 | 说明连接/版本问题，根据实际 tools/list 校正；未能验证就暂停，不换服务冒充完成 | 暂停生成 |

脚本报错由 AI 转译为以上用户提示；保留必要错误摘要供排查，不要求用户读 Python 堆栈。服务支持参数、费用和平台规则以实际核验为准，静态说明不能代替联调。
